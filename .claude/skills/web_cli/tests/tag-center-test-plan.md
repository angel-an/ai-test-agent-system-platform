# 营销云 - 标签中心 (Tag Center) 测试计划

## 概述

本文档为营销云"标签中心"（Tag Center）功能模块的测试计划。标签中心用于创建和管理会员标签，支持标签的增删改查、标签分组管理、为会员打标签等操作。

## 测试范围

| 项目 | 内容 |
|------|------|
| 项目标识符 | PR-3 |
| 功能 | GOS·数盈（营销云）- WF-1009 |
| 子功能 | 标签中心 - WSF-1031 (b95b49ef-461c-48c4-ba13-c494b310f618) |
| 测试类型 | 功能测试 |
| 优先级 | Medium |

## 测试环境

| 项目 | 内容 |
|------|------|
| 营销云 URL | https://mkt.eatizen.com.sg/saas-imarketing-web-pc |
| 集成入口 | BOC 控制台 → 产品详情 → 营销云 iframe |
| 会话恢复 | 使用 `/crm_full_state.json` 恢复登录状态 |
| iframe | 所有操作通过 `page.frameLocator('#systemIframe')` 访问 |
| 超时设置 | 单测试用例 300 秒超时 |

## 前置条件 (Prerequisites)

1. **认证要求**: 用户必须已登录 BOC 控制台，且有访问营销云的权限
2. **数据要求**: 营销云标签中心模块已配置并可用
3. **会话要求**: 使用 `/crm_full_state.json` 恢复会话状态
4. **菜单路径**: 营销云左侧导航栏 → 标签中心 (Tag Center)

### TS-06: 标签分组管理

| 项目 | 内容 |

| 名称 | 标签分组管理功能验证 |
| 优先级 | P1 |
| 类型 | 功能测试 |

**前置条件**:

**步骤**:
1. **查看分组**：验证标签分组列表/树形结构可见

   a. 点击"新增分组"或"管理分组"按钮

   c. 修改分组名称

   a. 选择空分组（或测试新建的分组）
   b. 点击"删除分组"
   c. 确认删除
   d. 验证分组已从列表中移除

**预期结果**:
- 分组的增删改查功能正常
- 创建分组后可立即在列表中看到
- 编辑分组后名称更新
- 删除分组后列表中移除

### TS-09: 标签名称校验 - 边界情况

| 项目 | 内容 |
|------|------|
| ID | TS-09 |
| 名称 | 标签名称输入校验测试 |
| 优先级 | P2 |
| 类型 | 边界测试 |

**前置条件**:
- 已进入标签中心页面

**步骤**:
1. **空名称校验**：
   a. 打开创建标签弹窗
   b. 不填写标签名称，直接点击保存
   c. 验证显示必填提示信息
2. **名称长度限制**：
   a. 输入超长标签名称（如 50 个字符以上）
   b. 验证是否有字符数限制提示
3. **特殊字符**：
   a. 输入含特殊字符的标签名称（如 @#$%）
   b. 验证系统是否正确处理
4. **重名校验**：
   a. 输入已存在的标签名称
   b. 验证系统提示名称重复

**预期结果**:
- 空名称提交时显示合适的错误提示
- 超长名称有截断或提示
- 特殊字符被正确处理（允许或提示不支持）
- 重名时显示重复提示

## 风险与缓解措施

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 标签中心无测试标签数据 | 无法执行编辑/删除测试 | 在测试脚本中先创建测试标签再操作 |
| 标签分组管理入口位置不确定 | 测试定位困难 | 使用多种定位器策略（文本、role、CSS） |
| 弹窗表单元素定位不稳 | 测试失败 | 使用 waitFor 和备用定位方案 |
