# 营销云 系统管理 (System Management) WSF-1035 测试计划

## 1. 概述

### 1.1 功能描述
系统管理 (System Management) - 营销云后台的核心管理功能模块，包括用户管理（用户列表查询、用户搜索、用户编辑）、角色管理（角色列表查看、角色创建与编辑、角色权限配置）、系统配置（系统参数查看与设置）、操作日志（操作日志查询与查看详情）等系统级管理功能。本功能位于营销云侧边栏菜单中，供系统管理员进行平台级运维管理。

### 1.2 测试目标
- 验证系统管理页面及各子页面的正常加载与元素完整性
- 验证用户管理列表显示、搜索、筛选功能
- 验证角色管理列表展示、角色创建、权限配置流程
- 验证系统配置参数查看与管理功能
- 验证操作日志查询、筛选与详情查看功能
- 验证各功能模块的异常输入处理

## 2. 前置条件

### 2.1 环境前置条件
1. UAT 环境服务正常运行，BOC 后台可访问
2. 营销云页面通过 BOC 后台 iframe 嵌入可正常加载
3. 用户已登录 DTCloud Business Console
4. 浏览器兼容：Chrome / Edge 最新版本

### 2.2 数据前置条件
1. 系统中至少存在 3-5 个用户账号（用于用户列表展示和搜索验证）
2. 系统中至少存在 2-3 个角色配置（用于角色列表和编辑测试）
3. 系统配置中存在可供查看的参数项
4. 系统中已有操作日志记录（至少若干条日志）
5. 测试账号具有系统管理菜单可见权限及系统管理的完整操作权限

### 2.3 每次用例执行的初始状态
- 用户已通过 BOC 控制台登录并进入营销云页面
- 侧边栏菜单可见，系统管理菜单项可见
- 如涉及数据修改的用例（创建角色、编辑角色），需在执行前确认测试数据可恢复

## 5. 测试数据

### 5.1 测试数据说明
- 用户搜索关键词：使用系统中已有的用户名或关键词（如已有用户的登录名、邮箱前缀等）
- 不存在的用户：使用特殊标记字符串确保系统中不存在（如 `__NON_EXISTENT_USER_999__`）
- 角色名称：测试数据使用时间戳后缀确保唯一性（如 `Test Role Auto_<timestamp>`）
- 角色描述：简要描述该角色的用途
- 操作日志筛选：使用日志列表中实际存在的操作类型进行筛选

### 5.2 测试注意事项
1. 创建/修改角色为破坏性操作，建议在独立测试环境执行
2. 如无法找到特定页面元素，测试可跳过或标记为警告
3. 创建角色后，建议在测试完成后清理测试数据
4. iframe 加载可能需要额外等待时间，设置充分的超时配置
5. 所有操作建议保存截图便于问题排查

## 6. 风险评估

| 风险项 | 影响 | 缓解措施 |
|--------|------|---------|
| 测试环境数据不足 | 搜索、编辑测试无法充分执行 | 准备充分的测试数据，至少包含 3 条以上不同账号的用户和角色 |
| 修改角色权限破坏性 | 影响其他用户权限 | 建议在独立测试环境执行，或在执行完查询类用例后再执行修改类用例 |
| iframe 加载延迟 | 元素定位超时 | 设置合理的等待时间和超时配置（30s+） |
| 界面 UI 变更 | 定位器失效 | 使用语义化定位器和多方案降级策略 |
| 子菜单展开/折叠机制 | 菜单定位困难 | 使用多级菜单定位策略，支持展开/折叠交互 |
