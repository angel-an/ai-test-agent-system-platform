# 测试证据脱敏规范（B5）

> 通用规范，不绑定具体项目。
> 目标：任何归档的证据（报告、截图、响应 JSON）都不暴露真实凭据和敏感数据。

---

## 1. 脱敏分级

| 敏感类型 | 处理方式 | 示例 |
|---|---|---|
| 凭据 | **禁止归档**，仅内存使用 | token、Cookie、password、API key |
| PII | 脱敏后归档 | 手机号 `183****0265`、会员 ID `M****001` |
| 密钥 | **禁止归档**，仅密钥系统使用 | 私钥、签名秘钥 |
| 普通数据 | 可直接归档 | 商品名称、积分值、配置参数 |

---

## 2. 禁止归档清单

以下数据**绝对禁止**出现在任何归档文件中：

| 数据类型 | 原因 | 处理方式 |
|---|---|---|
| 密码 | 高敏感 | 不记录，仅环境变量 |
| token | 高敏感 | 不记录，仅内存使用 |
| Cookie | 高敏感 | 不记录，仅内存使用 |
| API key | 高敏感 | 不记录，仅密钥系统 |
| 私钥 | 极高敏感 | 不记录，仅密钥系统 |
| 完整手机号 | PII | 脱敏为 `183****0265` |
| 完整身份证号 | PII | 脱敏为 `110**********1234` |
| 完整银行卡号 | PII | 脱敏为 `6222****8888` |

---

## 3. 脱敏规则

### 3.1 手机号

```
原始：18312340265
脱敏：183****0265（保留前 3 位和后 4 位）
```

### 3.2 会员 ID / 用户 ID

```
原始：M123456789
脱敏：M****789（保留前缀和后 3 位）
```

### 3.3 姓名

```
原始：张三
脱敏：张*（保留姓）
```

### 3.4 地址

```
原始：北京市海淀区xxx街道xxx号
脱敏：北京市海淀区***（保留到区/县）
```

### 3.5 响应 JSON 中的敏感字段

```json
// 原始响应（禁止直接归档）
{
  "memberId": "M123456789",
  "phone": "18312340265",
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "balance": 100.00
}

// 脱敏后归档
{
  "memberId": "M****789",
  "phone": "183****0265",
  "token": "[REDACTED]",
  "balance": 100.00
}
```

### 3.6 截图中的敏感信息

| 场景 | 处理方式 |
|---|---|
| 登录页面含密码 | 截图前清空密码框，或截图后打码 |
| 浏览器开发者工具含 token | 关闭开发者工具后截图，或截图后打码 |
| 响应预览含敏感数据 | 截图前脱敏，或截图后打码 |
| 日志输出含凭据 | 不截图日志，或截图前过滤 |

---

## 4. 归档前检查清单

任何证据包归档前，必须完成以下检查：

| 检查项 | 方法 | 通过标准 |
|---|---|---|
| 响应 JSON 无 token | 文本搜索 `"token"`、`"accessToken"`、`"cookie"` | 无匹配或值为 `[REDACTED]` |
| 响应 JSON 无密码 | 文本搜索 `"password"`、`"pwd"`、`"secret"` | 无匹配或值为 `[REDACTED]` |
| 手机号已脱敏 | 正则匹配 `1[3-9]\d{9}` | 无完整手机号 |
| 截图无敏感信息 | 人工目视检查 | 无密码、token、完整手机号 |
| 日志无凭据 | 文本搜索 `"Bearer"`、`"Authorization"` | 无匹配或值为 `[REDACTED]` |
| 文件名无敏感信息 | 检查文件名 | 无手机号、ID、密码 |

**检查工具**（可选）：
```bash
# 快速扫描 token
grep -r "token" workspace/evidence/ | grep -v "REDACTED"

# 快速扫描完整手机号
grep -rE "1[3-9][0-9]{9}" workspace/evidence/

# 快速扫描密码
grep -ri "password" workspace/evidence/ | grep -v "REDACTED"
```

## 5. 证据包结构

脱敏后的证据包结构：

```
workspace/evidence/{project}-{operation}-{timestamp}/
├── README.md              # 证据包说明（含脱敏声明）
├── request/               # 请求（已脱敏）
│   └── api_request.json
├── response/              # 响应（已脱敏）
│   └── api_response.json
├── screenshots/           # 截图（已检查）
│   └── step_01_login.png
├── logs/                  # 日志（已过滤）
│   └── execution.log
└── audit/                 # 审批记录
    └── approval_l2.md
```

**README.md 模板**：
```markdown
# 证据包：{project}-{operation}-{timestamp}

## 脱敏声明
- [x] 响应 JSON 已脱敏（token、密码已替换为 [REDACTED]）
- [x] 手机号已脱敏（183****0265）
- [x] 截图已检查，无敏感信息
- [x] 日志已过滤，无凭据
- [x] 文件名无敏感信息

## 操作信息
- 项目：PR-2
- 操作：充值
- 时间：2026-09-06 10:30
- 执行人：QA xxx
- 审批单号：CONF-20260906-001

## 证据清单
- request/api_request.json：请求参数
- response/api_response.json：响应结果（已脱敏）
- screenshots/step_01_login.png：登录截图
- logs/execution.log：执行日志（已过滤）
- audit/approval_l2.md：审批记录
```
