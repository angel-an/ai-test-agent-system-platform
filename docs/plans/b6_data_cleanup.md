# 测试数据清理规范（B6）

> 通用规范，不绑定具体项目。
> 目标：项目结束后，测试数据、流水、凭据、证据包都得到妥善处理，无残留影响。

---

## 1. 清理分级

| 清理类型 | 定义 | 适用场景 | 责任人 |
|---|---|---|---|
| 自动清理 | 系统或脚本自动处理 | token 过期、会话超时 | 系统 |
| 手动清理 | QA 手动删除或标记 | 测试数据标记为删除 | QA |
| 业务清理 | 业务确认后清理 | 充值流水冲正、积分补充 | QA / 业务 |
| 联合清理 | 多角色共同确认 | 批量数据、复杂交易 | QA / 业务 / 开发 |

---

## 2. 清理时机

| 时机 | 触发条件 | 清理范围 |
|---|---|---|
| 阶段清理 | 每轮测试结束后 | 本轮测试数据、临时文件 |
| 项目清理 | 项目交付后 | 全部测试数据、流水、凭据 |
| 异常清理 | 测试中断或失败 | 已产生但未完成的数据 |
| 定期清理 | 按保留策略执行 | 过期证据包、日志 |

**保留期限**：
- 证据包：项目结束后 7 天（可调整）
- 审批记录：项目结束后 30 天（L2）/ 90 天（L3）
- 审计日志：按安全策略
- 凭据：使用后立即清理

---

## 3. 通用清理检查表

项目结束后必须完成以下检查：

| 检查项 | 状态 | 责任人 | 备注 |
|---|---|---|---|
| 测试流水是否已冲正或标记为测试数据 | ☐ | QA / 业务 | 充值、退款、兑换等 |
| 测试余额/积分是否已恢复初始状态 | ☐ | QA / 业务 | 核对前后一致 |
| 批量导入的数据是否已清理 | ☐ | QA / 业务 | 删除或标记测试数据 |
| 测试商品/配置是否已删除或标记 | ☐ | QA / 业务 | CRM 配置恢复 |
| 环境变量中的凭据是否已从本地移除 | ☐ | QA | `.env` 文件清理 |
| 截图、报告中的敏感数据是否已脱敏 | ☐ | QA | 按 B5 规范 |
| 证据包是否已按保留期限处理 | ☐ | QA | 保留或清理 |
| 临时文件是否已删除 | ☐ | QA | `workspace/tmp/` 等 |
| 责任人是否已确认无残留影响 | ☐ | 业务 / QA | 联合确认 |

| CRM 测试装修配置是否已恢复 | ☐ | 恢复上一版本配置 |

## 6. 清理流程

```
项目结束 / 阶段结束
  → QA 填写清理检查表
    → 按检查项逐项执行清理
      → 核对清理前后状态
        → 业务确认无残留
          → 归档清理记录
            → 按保留期限处理证据包
```

### 6.1 阶段清理流程

1. 本轮测试结束后，QA 检查本轮产生的测试数据
2. 冲正或标记测试数据
3. 核对状态
4. 记录清理日志

### 6.2 项目清理流程

1. 项目交付后，QA 填写完整清理检查表
2. 按检查表逐项执行（可能需要业务/开发配合）
3. 核对所有数据已恢复初始状态
4. 业务确认无残留影响
5. 归档清理记录
6. 按保留期限处理证据包（保留或删除）
