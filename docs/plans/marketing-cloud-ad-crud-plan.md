## 风险与应对

| 风险 | 应对措施 |
|------|----------|
| 验证码干扰登录 | 使用 SmartAuthRouter，启用 OCR 识别 |
| 页面加载慢 | 增加 wait_for_load_state 和 expect 超时 |
| 动态元素ID | 优先使用文本内容、ARIA 标签定位 |
| 弹窗/遮罩层 | 使用 expect 等待元素可见/可点击 |
| 数据依赖 | 使用唯一标识（时间戳）创建测试数据 |
