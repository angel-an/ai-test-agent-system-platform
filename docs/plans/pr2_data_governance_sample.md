## 数据登记

### 1. 登录账号与凭据

| 字段 | 内容 |
|---|---|
| 数据对象 | 控制台登录账号 |
| 数据标识 | 用户名：`PR2_API_USER`（环境变量） |
| 操作类型 | 登录（获取 access-token） |
| 风险等级 | S（凭据和敏感数据） |
| 是否需要审批 | 否（只读登录，无业务影响） |
| 预期影响 | 获取会话 token，无数据变更 |
| 回滚方式 | token 过期自动失效，或手动退出登录 |
| 证据位置 | 不记录密码；token 仅内存使用 |
| 责任人 | QA |

**凭据引用方式**：
- `PR2_API_USER` / `PR2_API_PASSWORD`：环境变量
- `PR2_ACCESS_TOKEN` / `PR2_COOKIE_HEADER`：环境变量（已知 token 时跳过登录）
- 禁止：脚本硬编码、报告截图含密码、日志输出 token

---

### 2. 会员查询（只读）

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员账户信息 |
| 数据标识 | 手机号：`PR2_STORAGE_ACCOUNT_NO`（环境变量，示例：183****0265） |
| 操作类型 | 查询（`/api/icdp/v1/memberCard/account/page`） |
| 风险等级 | L1（UAT 只读数据） |
| 是否需要审批 | 否 |
| 预期影响 | 返回会员余额、积分等，无数据变更 |
| 回滚方式 | 无需回滚 |
| 证据位置 | 响应 JSON（脱敏后归档） |
| 责任人 | QA |

---

### 3. 充值写入

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员余额、充值流水 |
| 数据标识 | 手机号：`PR2_STORAGE_ACCOUNT_NO`（环境变量） |
| 操作类型 | 创建（`/api/icdp/v1/recharge/reSetRecharge`） |
| 风险等级 | L2（可回滚正常写入） |
| 是否需要审批 | 是，业务确认 |
| 预期影响 | 余额增加，流水 +1 条，金额按测试计划 |
| 回滚方式 | 退款冲正（调用退款接口或人工核对后冲正） |
| 证据位置 | `workspace/evidence/pr2-recharge-{timestamp}/` |
| 责任人 | QA / 业务 |

**充值参数**：
- `type`: 0（充值）
- `phones`: 环境变量指定
- `amount`: 测试计划指定（建议小额，如 0.01 元）
- `rechargeBizType`: ENTERPRISE

---

### 4. 退款/冲正

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员余额、退款流水 |
| 数据标识 | 手机号：`PR2_STORAGE_ACCOUNT_NO`（环境变量） |
| 操作类型 | 修改（`/api/icdp/v1/recharge/reSetRecharge`，type=1） |
| 风险等级 | L3（风险或不可逆操作） |
| 是否需要审批 | 是，业务确认 + 流水核对 |
| 预期影响 | 余额扣减，流水 +1 条 |
| 回滚方式 | 人工核对后补充值；或记录冲正流水 |
| 证据位置 | `workspace/evidence/pr2-refund-{timestamp}/` |
| 责任人 | QA / 业务 / 开发 |

**退款参数**：
- `type`: 1（退款）
- `phones`: 环境变量指定
- `amount`: 与对应充值金额一致
- `rechargeBizType`: ENTERPRISE

---

### 5. 流水核对

| 字段 | 内容 |
|---|---|
| 数据对象 | 充值/退款流水记录 |
| 数据标识 | 按时间范围查询 |
| 操作类型 | 查询（`/api/icdp/v1/memberCard/account/page`） |
| 风险等级 | L1（UAT 只读数据） |
| 是否需要审批 | 否 |
| 预期影响 | 返回流水列表，用于核对充值/退款结果 |
| 回滚方式 | 无需回滚 |
| 证据位置 | 响应 JSON（脱敏后归档） |
| 责任人 | QA |

**核对要点**：
- 充值后余额 = 充值前余额 + 充值金额
- 退款后余额 = 退款前余额 - 退款金额
- 流水记录数与操作次数一致

---

### 6. 批量导入

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员账户批量创建/更新 |
| 数据标识 | 批量文件（CSV/Excel） |
| 操作类型 | 创建（`/api/icdp/v1/memberInfoBestore/import/memberAccount`） |
| 风险等级 | L2（可回滚正常写入） |
| 是否需要审批 | 是，业务确认 |
| 预期影响 | 批量创建会员账户，影响记录数按文件行数 |
| 回滚方式 | 删除导入记录或标记为测试数据 |
| 证据位置 | 导入文件、响应结果、批量操作日志 |
| 责任人 | QA / 业务 |

**前置依赖**：
- OSS 上传策略（`/api/data/v1/huieryun/objectstorage/policy/cube/getpolicy`）
- 文件上传后获取 URL，再调用批量导入

## 数据分级汇总

| 接口 | 操作类型 | 风险等级 | 审批 | 回滚方式 |
|---|---|---|---|---|
| `ssouser/login` | 登录（获取 token） | S | 否 | token 过期/退出 |
| `memberCard/account/page` | 查询余额/流水 | L1 | 否 | 无需回滚 |
| `reSetRecharge`（type=0） | 充值 | L2 | 是 | 退款冲正 |
| `reSetRecharge`（type=1） | 退款 | L3 | 是 | 人工核对补充值 |
| `memberInfoBestore/import` | 批量导入 | L2 | 是 | 删除/标记测试数据 |
| `objectstorage/policy` | 获取上传策略 | L1 | 否 | 无需回滚 |

## 使用说明

1. **执行前**：核对风险等级和审批状态，确认环境变量已配置
2. **执行中**：按 L1→L2→L3 顺序执行，L3 操作必须有业务确认
3. **执行后**：按清理检查表核对，敏感数据脱敏，凭据清理
4. **归档时**：证据包按 `workspace/evidence/pr2-{操作}-{timestamp}/` 存放

**注意**：本样例为 PR-2 实际治理记录，其他项目应按 `test_data_governance_template.md` 的通用模板重新登记。
