# PR-9 积分商城测试数据治理样例

> 基于 PR-9 积分商城交付材料填充的第二份数据治理样例。
> 用于验证 `test_data_governance_template.md` 通用模板是否适用于不同业务场景。
> 所有敏感数据已脱敏，凭据引用环境变量。

---

## 项目信息

| 字段 | 内容 |
|---|---|
| 项目/环境 | PR-9 / UAT |
| 测试范围 | 积分商城（商品列表、积分兑换、订单管理、交易记录、积分明细） |
| 负责人 | admin |
| 数据保留期限 | 项目结束后 7 天内清理 |

---

## 数据登记

### 1. 会员登录与凭据

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员登录账号 |
| 数据标识 | 会员 ID：`PR9_MEMBER_ID`（环境变量） |
| 操作类型 | 登录（获取会话 token） |
| 执行风险等级 | L1（UAT 只读数据，登录本身不修改状态） |
| 数据敏感等级 | 凭据（token/session） |
| 是否需要审批 | 否 |
| 预期影响 | 获取会话 token，无业务数据变更 |
| 回滚方式 | token 过期自动失效 |
| 证据位置 | 不记录密码；token 仅内存使用 |
| 责任人 | QA |

**凭据引用方式**：
- `PR9_MEMBER_ID` / `PR9_MEMBER_TOKEN`：环境变量
- 禁止：脚本硬编码、报告含 token、日志输出 session

---

### 2. 积分商品列表查询（只读）

| 字段 | 内容 |
|---|---|
| 数据对象 | 积分商品列表 |
| 数据标识 | 商品 ID 列表（公开数据） |
| 操作类型 | 查询（获取[当前等级可见]且[活动周期内]的商品） |
| 执行风险等级 | L1（UAT 只读数据） |
| 数据敏感等级 | 普通（商品名称、积分值、图片 URL 为公开配置） |
| 是否需要审批 | 否 |
| 预期影响 | 返回商品列表，无数据变更 |
| 回滚方式 | 无需回滚 |
| 证据位置 | 响应 JSON（商品列表截图） |
| 责任人 | QA |

**查询参数**：
- 等级可见过滤：当前会员等级
- 活动周期：当前时间在商品开始~结束范围内
- 预热提前 N 天：当前时间在（开始时间 - N 天）范围内也显示
- CMS 排序：按配置排序值展示

---

### 3. 预热商品状态查询（只读）

| 字段 | 内容 |
|---|---|
| 数据对象 | 预热期商品状态 |
| 数据标识 | 商品 ID（公开数据） |
| 操作类型 | 查询（列表页/详情页倒计时与按钮态） |
| 执行风险等级 | L1（UAT 只读数据） |
| 数据敏感等级 | 普通 |
| 是否需要审批 | 否 |
| 预期影响 | 返回倒计时文案、按钮状态（置灰/可点） |
| 回滚方式 | 无需回滚 |
| 证据位置 | 截图（列表页 + 详情页） |
| 责任人 | QA |

**状态校验点**：
- 预热期：列表显示「还有 N 天开始」，按钮 redeem 置灰不可点
- 预热期详情：显示「还有 N 天开始」，按钮「即将开始」置灰
- 活动期：列表显示「还有 N 天结束」，按钮 redeem 可点
- 活动期详情：显示「还有 N 天结束」，按钮「立即兑换」可点

---

### 4. 积分兑换（写入）

| 字段 | 内容 |
|---|---|
| 数据对象 | 会员积分余额、兑换订单、积分流水 |
| 数据标识 | 会员 ID：`PR9_MEMBER_ID`（环境变量，PII） |
| 操作类型 | 创建（兑换商品，扣减积分，生成订单） |
| 执行风险等级 | L2（可回滚正常写入） |
| 数据敏感等级 | PII（会员 ID）+ 普通（积分值、订单号） |
| 是否需要审批 | 是，业务确认 |
| 预期影响 | 积分余额扣减，兑换订单 +1，积分流水 +1 |
| 回滚方式 | 人工核对后补充积分值；或记录冲正流水 |
| 证据位置 | `workspace/evidence/pr9-exchange-{timestamp}/` |
| 责任人 | QA / 业务 |

**兑换参数**：
- 商品 ID：环境变量或查询结果指定
- 积分值：按商品配置
- 幂等键：防止重复兑换（需确认）

**前置校验**：
- 积分余额 ≥ 商品所需积分
- 商品库存 > 0
- 活动周期内

## 与 PR-2 样例的对比验证

| 对比项 | PR-2（储值充值） | PR-9（积分商城） | 模板通用性 |
|---|---|---|---|
| 业务场景 | 充值、退款、流水 | 兑换、订单、装修 | ✅ 不同场景均可覆盖 |
| 数据对象 | 余额、流水、批量导入 | 积分、订单、商品配置 | ✅ 模板字段足够通用 |
| 风险等级分布 | L1/L2/L3 | L1/L2 | ✅ 分级标准适用 |
| 敏感数据类型 | PII（手机号）、凭据（token） | PII（会员 ID）、凭据（token） | ✅ 敏感等级适用 |
| 回滚方式 | 退款冲正 | 人工补充积分 | ✅ 回滚字段足够灵活 |
| 审批要求 | L2/L3 需审批 | L2 需审批 | ✅ 审批规则一致 |

**结论**：`test_data_governance_template.md` 通用模板适用于不同业务场景，字段和分级标准足够灵活。
